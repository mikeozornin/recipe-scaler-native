# Code Review: master (spec 072-vkusvill-integration)

**Дата:** 2026-08-27  
**Scope:** незакоммиченные изменения по [specs/072-vkusvill-integration](specs/072-vkusvill-integration/spec.md)  
**Ветка:** `master` (изменения spec 066 side-by-side в diff не ревьюились)

## Summary

Реализация spec 072 в целом соответствует контракту: тогл через `/api/settings`, shared `VkusvillSettingsStore`, `openAssistantWithMessage` с `requestId`, deferred autosend, logout invalidation через `assistantSessionEpoch`. Async lifecycle для settings (generation/refreshEpoch, FIFO mutex на PUT) и тесты на гонки — сильная сторона.

**Области ревью:** Business Logic, Architecture, Standards.  
**Пропущено:** Security (нет новых auth/secret surface; REST по существующему паттерну), Performance (нет hot paths).

**Уровень риска:** средний — один дефект autosend при повторном «Купить» с уже открытым ассистентом.

## Findings (sorted by priority)

### High

1. **[Business Logic]** Повторный buy при открытом sheet не выполняет autosend (US3 #2, edge case «assistant already open»)

   - **Где:** `AssistantSheet.swift` — `startNewChat` (~461–476), `scheduleExternalSendIfNeeded` (~519–525)
   - **Impact:** После первого send в той же сессии sheet `streamTask` остаётся non-nil (cancel без `= nil`). `scheduleExternalSendIfNeeded` трактует это как «stream in flight» и кладёт промт в composer вместо `launchSend`. Нарушает spec: каждый тап buy → новый тред **и** autosend без второго Send.
   - **Recommendation:** В `startNewChat` / `openThread` / teardown после `streamTask?.cancel()` ставить `streamTask = nil`. Лучше проверять `isSending`, а не `streamTask != nil`. Добавить тест: buy → дождаться autosend → buy снова без dismiss → первое user-сообщение = промт.

2. **[Standards / Spec]** Иконка buy-кнопки не совпадает со spec (FR-VV-002)

   - **Где:** `ShoppingListView.swift` (~93) — `systemName: "banknote"`; spec и `docs/UI.md` требуют `"cart"`.
   - **Impact:** Расхождение с web-parity checklist и acceptance US2; QA по spec/docs упадёт.
   - **Recommendation:** Заменить на `"cart"`, **или** согласованно обновить spec + `docs/UI.md`, если намеренно выбран Cash/banknote как в web Lucide.

### Medium

3. **[Architecture]** `VkusvillSettingsStore` и `AsyncFIFOMutex` внутри `AccountAPI.swift`

   - **Impact:** Смешение REST transport, observable state и generic primitive в одном файле; расходится с `FeatureAdoptionStore` / `SystemBannerStore` как отдельными типами.
   - **Recommendation:** Вынести в `VkusvillSettingsStore.swift` (или переименованный store) и `Utils/AsyncFIFOMutex.swift`.

4. **[Architecture]** Vkusvill-named store владеет cross-cutting `/api/settings`, включая nutrition

   - **Impact:** `AccountSettingsViewModel` зависит от feature-specific store для общего флага; `isUpdating` (Vkusvill PUT) блокирует apply refresh и может не обновить `nutritionEnabledFromServer` во время toggle.
   - **Recommendation:** Нейтральный `UserSettingsStore` / `AccountUserSettingsStore` с field-scoped update gates; Vkusvill — один consumer.

5. **[Architecture]** Split nutrition read vs write

   - **Impact:** Read через store mirror, write через VM → `AccountAPI.updateNutritionEnabled` без обновления mirror; resync только на reconnect/profile refresh.
   - **Recommendation:** Единый owner для nutrition в shared settings store **или** вернуть dedicated read path в VM с координированным fetch.

6. **[Standards]** Нет UITest ru-flow (plan verification)

   - **Impact:** Selectors (`vkusvill_toggle`, `vkusvill_buy_button`) есть, тестов нет — регрессии gating / open-with-message не ловятся в CI.
   - **Recommendation:** UITest ru → toggle → buy → prompt в sheet (stub assistant), или явный defer в plan с rationale.

7. **[Standards]** Plan invariant «autosend == localized prompt» не покрыт end-to-end

   - **Impact:** Coordinator-тесты используют hardcoded `"Собери корзину"`; смена ключа в `ShoppingListView` не упадёт в CI.
   - **Recommendation:** Unit-тест на `Bundle.currentLocalizedString("vkusvill.assistant-prompt")` в связке с entry point.

### Low

8. **[Business Logic / Standards]** Два источника ru-gating

   - **Где:** `AccountView` — `appLanguage == .ru`; `ShoppingListView` — `@Environment(\.locale)`.
   - **Impact:** Сейчас синхронизированы через `ContentView`; риск рассинхрона при смене языка без update locale env.
   - **Recommendation:** Единый helper на `AppLanguagePreference.current`.

9. **[Standards]** `docs/UI.md` описывает `cart`, код — `banknote`

   - Дублирует finding #2; исправляется вместе с иконкой.

10. **[Standards]** Spec/plan status In Progress при готовой реализации

    - **Recommendation:** Обновить статус и verification checklist в plan после фиксов.
