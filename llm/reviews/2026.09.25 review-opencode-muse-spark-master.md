# Code Review: master

## Summary
Range `HEAD~20..HEAD` (`4de8a78..5322422`, 217 files, +18.6k/−2k) — specs 074 process-table, 075 hands-free cook controls, 076 clipboard import banner, 077 iOS release notes, plus timer/auth/Yjs follow-ups. ## Findings (sorted by priority)

### High
1. **[Performance]** `YjsMergeHelper` serializes full Y updates on `@MainActor` (`Data → [NSNumber] → JSON → JS eval`).
   - Impact: 1 MB update → ~1M NSNumbers + multi-MB string on main; reconnect drain blocks UI for hundreds of ms.
   - Recommendation: Serialize off-main, hop to main only for `evaluateJavaScript`; or send base64/`ArrayBuffer`; batch per-recipe merges.
   - Refs: `RecipeScalerNative/Services/YjsSync/YjsMergeHelper.swift:54-70,123-130`; `YjsSyncService.swift:499-526`.
2. **[Performance]** `SpotlightIndexer.performReindex` sequential `await peekRecipeData` per dirty entry (full Y decode + HTML) instead of existing `peekSearchIndex`/`readSearchIndex` projection.
   - Impact: Bulk import / first launch = hundreds of serial full decodes on `@MainActor`.
   - Recommendation: Use `readSearchIndex` for snippet path + bounded `TaskGroup` (4–8).
   - Refs: `RecipeScalerNative/Services/SpotlightIndexer.swift:151-160`; `YjsSyncService.swift:1562-1579`.
3. **[Architecture]** `ProcessTableAPI` bypasses composition root + Core facade rules (`APIClient.shared.requestJSON` + manual `guard success`).
   - Impact: Untestable without seam, hidden 180s timeout, Native owns wire contract, duplicates unwrap logic.
   - Recommendation: Move to `RecipeScalerCore/Networking/Endpoints/ProcessTableAPI.swift` as `public enum`, inject `APIClient`, use `unwrapResponse(fallbackCode:)`.
   - Refs: `RecipeScalerNative/Services/ProcessTableAPI.swift:8-9`; `ViewModels/ProcessTableRebuildModel.swift:25,44`.
4. **[Architecture]** `AwakeScrollController` constructs `voiceEngine`/`captureSession` internally, couples to `AwakeHandsFreeStorage` statics and OS singletons; no `stopForLogout` scoping.
   - Impact: Second detail instance = second camera/mic stack; permission-denied writes go to `UserDefaults` from controller; unmockable except bool seams.
   - Recommendation: Inject engine/storage/permission protocols from `AppContainer` factory, or document screen-scoped intent in `specs/075/plan.md`.
   - Refs: `RecipeScalerNative/Services/Cooking/AwakeScrollController.swift:33-48,253-272,343-367`.
5. **[Architecture]** `DiscoverAPI.fetchPublicProfile` embeds retry (`1...4` + `sleep(2s*attempt)`, no jitter/cancel) in Native facade; Core migration stalled.
   - Impact: Diverges from central timeout policy; Native accumulates wire logic.
   - Recommendation: Move DTO to `Core/Networking/Endpoints/DiscoverAPI.swift`, extract shared `RetryPolicy`.
   - Refs: `RecipeScalerNative/Services/DiscoverAPI.swift:242-262`.
6. **[Standards]** E2E selector drift — new a11y IDs (`clipboard-import-banner*`, `release_notes_*`, `recipe_process_table_*`) have no mirror in `Selectors.swift` (stops at `recipeImageUpload`).
   - Impact: Page-objects cannot target new chrome; E2E coverage rots.
   - Recommendation: Mirror constants incl. `releaseNotesSheetRowPrefix` func.
   - Refs: `RecipeScalerNative/AccessibilityIdentifiers.swift:165-167,190-195,236-240`; `RecipeScalerNativeUITests/Helpers/Selectors.swift:149-169`.
7. **[Standards]** `LocalizationConsistencyTests` gap — 12 keys used in range not in test list (`import.clipboard-banner.message`, `recipe.process-table.*`, `edit.servings`, `description.instructions`, `Instructions`, etc.).
   - Impact: Missing `ru` would not fail CI for 074/075/076 copy.
   - Recommendation: Extend `keys` array (all resolve in `Localizable.xcstrings` — verified).
   - Refs: `RecipeScalerNativeTests/LocalizationConsistencyTests.swift:31+`.

### Medium

    - Refs: `RecipeScalerNative/Models/YDoc/ProcessTableMatrix.swift:147`; `Views/Cooking/ProcessTableGrid.swift:162`.
