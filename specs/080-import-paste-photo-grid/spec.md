## Границы

**В scope:**

- Вкладка «Текст»: баннер «Вставить», пока в буфере ссылка; карточка «Отправляйте ссылки прямо из браузера» с мини-шитом «Поделиться» и крестиком. Плейсхолдер поля прежний.

- Сохранение снятого фото в медиатеку.
- Изменения серверного API и Share Extension.

## User Scenarios

### US1 — Ссылка в буфере → импорт одним нажатием (P1)

Человек скопировал ссылку в Safari и открыл импорт. Сверху баннер «Импортировать сайт из буфера обмена?» (как на главной, 076) с системной кнопкой «Вставить». Тап — ссылка в поле, импорт стартует сразу (поле было пустым и вставлена только ссылка).

**Acceptance:**
1. Баннер виден, только если в буфере ссылка и поле пустое; иначе его нет.
2. Проверка буфера — та же, что у баннера 076 (`detectPatterns(.probableWebURL)` / `hasURLs`), без системного алерта «Разрешить вставку».
3. Вставленный текст без ссылки попадает в поле и не запускает импорт.

### US2 — Подсказка про «Поделиться» (P2)

Под полем — карточка с мини-шитом «Поделиться»: AirDrop, Сообщения, Recipe Scaler (в цвете, выделен, пульсирует), Заметки (серые). Reduce Motion — без пульса. Крестик скрывает карточку навсегда на этом устройстве (UserDefaults `import-share-hint-dismissed`).

### US3 — Фото из сетки (P1)

Вкладка «Фото»: заголовок-меню альбома («Недавние ⌄»), счётчик «N из 8», сетка: камера, затем фото новыми сверху. Тап по фото — кружок с порядковым номером; 9-е выбрать нельзя (остальные приглушены). Тап по камере — съёмка, снимок появляется после ячейки камеры уже выбранным. «Импортировать» отправляет выбранное в порядке выбора.

**Acceptance:**
1. Доступ не спрошен → запрос при первом открытии вкладки.
2. Limited → строка «Видны только разрешённые фото» + «Изменить» (`presentLimitedLibraryPicker`).
3. Denied/restricted → текст, «Открыть настройки» и запасной системный `PhotosPicker`.
4. Живое превью камеры — только если доступ к камере уже дан; иначе ячейка с иконкой, доступ спрашивает сама камера при тапе.
5. HEIC/JPEG/PNG уходят как есть; прочие форматы и файлы больше лимита перекодируются в JPEG.
