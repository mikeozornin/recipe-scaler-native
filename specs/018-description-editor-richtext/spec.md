# Спецификация: rich-text паритет редактора описания

**Ветка**: `018-description-editor-richtext`  
**Дата**: 2026-06-03  
**Статус**: Draft (перенос недоделок из 006); UI и inline Tiptap — [019-recipe-description-inline-edit](../019-recipe-description-inline-edit/spec.md)  
**Зависимости**: `019` (inline + нативная панель), `006` (мост Yjs), `004` (read-only рендер)  
**Эталон**: Tiptap в `recipe-scaler-web/recipe-scaler` `recipe-detail`, custom-ноды ingredient/timer

## Контекст

В 006 отгружен базовый редактор: WKWebView с `contentEditable`, мост в `Y.XmlFragment('description')` через `yjs.bundle.js`, тулбар bold/italic/H1/bullet, sync + offline.

Не закрыто из 006:

- ссылки (US2);
- вставка нод `ingredient` и `timer` с атрибутами веба (US3);
- запуск локального таймера из timer-ноды в режиме просмотра (FR-DESC-EDIT-005);
- проверка, что генерируемый XML совместим с Tiptap/ProseMirror веба на сложной разметке.

## Цель

Довести редактирование описания до видимого паритета с вебом по форматированию и custom-нодам, сохранив бинарную совместимость Yjs.

## Пользовательские сценарии

### US1 — Ссылки (P1)

**Когда** пользователь выделяет текст и применяет «ссылку», **тогда** в `XmlFragment` появляется тот же mark, что у веба; на вебе ссылка кликабельна после sync.

### US2 — Ingredient node (P2)

**Когда** пользователь вставляет ссылку на ингредиент, **тогда** нода с `data-ingredient-id` и атрибутами как на вебе; read-рендер (004) показывает масштабированное количество.

### US3 — Timer node (P2)

**Когда** пользователь вставляет таймер, **тогда** нода с `duration`/`type` как на вебе.

### US4 — Запуск таймера из описания (P1)

**Дано** режим просмотра (004) или редактирования, **когда** tap по timer-ноде, **тогда** создаётся локальный таймер (`TimerManager`) — паритет mobile веба. (Кросс-девайс sync таймеров — в 014.)

### US5 — XML-паритет (P1)

**Когда** на iOS создаётся сложная разметка (вложенные списки, заголовки, ссылки, ноды), **тогда** веб открывает её без ошибок ProseMirror и наоборот.

## Требования

### FR-018-001 — Тулбар

Добавить кнопки: ссылка, ingredient, timer (минимум — ссылка + один из node-типов в MVP).

### FR-018-002 — Атрибуты нод

Соответствие схеме веба (`docs/YJS-SCHEMA.md` + Tiptap-ноды). Мутации только через yrs/мост, не REST.

### FR-018-003 — Запуск таймера

Связать timer-ноду с `TimerManager`; в read-view (`RecipeDescriptionView`/`StepsSection`) timer-ноды кликабельны.

### FR-018-004 — Совместимость

Тест round-trip: iOS-разметка → веб → iOS без потерь на наборе фикстур.

## Вне scope

- Полная замена `contentEditable` на нативный движок ProseMirror
- Кросс-девайс sync таймеров (014)
- Миграция v1/v2 → v3

## Критерии успеха

- **SC-001**: Ссылка, вставленная на iOS, кликабельна на вебе после sync.
- **SC-002**: Timer-нода iOS → веб показывает таймер с тем же duration.
- **SC-003**: Tap timer-ноды в просмотре → локальный таймер запущен.
- **SC-004**: Round-trip сложной разметки без ошибок ProseMirror.
