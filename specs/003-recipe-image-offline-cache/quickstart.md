# Quickstart: проверка офлайн-кэша изображений

**Дата**: 2026-06-02  
**Спека**: [spec.md](./spec.md)

## Предусловия

- Backend доступен (`Config.swift`)
- Пользователь с рецептами, у части из них загружено фото (непустой `imageUrl` в коллекции)
- Симулятор или устройство iOS 17+

## 1. Превью в списке (онлайн)

1. Войти в приложение, дождаться `connectionState` = connected (зелёная галочка).
2. Открыть список рецептов.
3. **Ожидание**: у рецептов с фото справа превью 44×44; у остальных — только emoji/точка и название.
4. (Опционально) В Xcode → Debug → View Debugging — убедиться, что нет массовых запросов к `/image` при скролле после первой загрузки.

## 2. Офлайн после кэширования

1. Выполнить п.1, подождать появления превью.
2. Включить режим полёта на симуляторе/устройстве.
3. Force-quit приложения, запустить снова.
4. **Ожидание**: список и превью отображаются без сети; индикатор — disconnected / wifi.slash.
5. Подождать ~10–30 с онлайн (фоновый prefetch preview + full), затем снова режим полёта.
6. Открыть рецепт с фото — шапка 250pt с full из `Caches/RecipeImages/{id}_full.webp`, без запросов к API.

## 3. Офлайн без предварительного кэша

1. Удалить приложение (сброс Caches + UserDefaults).
2. Установить заново, **не** открывать список долго онлайн — сразу режим полёта после login (если коллекция уже в SQLite из прошлой сессии — пропустить шаг).
3. **Ожидание**: строки рецептов с `imageUrl` без картинки (пустой слот или без превью), приложение не падает.

## 4. Обновление фото с веба

1. На вебе заменить изображение рецепта (новый `imageUrl` / новый файл).
2. На iOS онлайн — дождаться sync коллекции или pull-to-refresh списка (переоткрыть список).
3. **Ожидание**: превью обновилось после фонового prefetch.

## 5. Удаление фото

1. На вебе удалить изображение рецепта (`imageUrl` пустой).
2. После sync на iOS.
3. **Ожидание**: превью исчезло из строки списка.

## Отладка

```bash
# Путь к кэшу на симуляторе (подставить container UUID из ~/Library/Developer/CoreSimulator/Devices/...)
ls "$(xcrun simctl get_app_container booted com.recipescaler.native data)/Library/Caches/RecipeImages/"
```

Ожидаемые файлы: `{recipeId}_preview.webp`, `{recipeId}_full.webp`.
