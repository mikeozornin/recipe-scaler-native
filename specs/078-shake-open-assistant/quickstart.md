# Quickstart: 078 Shake → open assistant

1. Build & run on Simulator or device.
2. Profile → Параметры / Preferences → toggle **Shake to open assistant** ON.
3. Leave Profile. On Recipes list: Device → Shake (Simulator: **Device → Shake** or ⌘⌃Z). Expect assistant sheet + recording UI; empty/new chat.
4. Open a recipe card. Shake again. Expect recipe chip in attachments + recording.
5. Toggle OFF. Shake → no open.
6. Cold start: toggle state persists; default for fresh install is OFF.
