# Quickstart — 019 inline description editor

Ручная проверка iOS ↔ web после внедрения фаз 019.

## Предусловия

- Симулятор iOS 18+, debug auto-login
- v3-рецепт с ингредиентами и непустым описанием
- Тот же рецепт открыт на вебе (mobile width) для сравнения

## SC-001 — Один Edit, без sheet

1. Открыть рецепт v3 → **Edit**.
2. Прокрутить: ингредиенты **выше** блока инструкций.
3. Изменить имя ингредиента, затем tap в текст инструкций, набрать абзац.
4. **Done** один раз — выход из edit.
5. **Ожидание:** sheet «Редактор описания» **не** появлялся.

## SC-002 — Sync на веб

1. В Edit изменить уникальную фразу в инструкции → Done → подождать ≤ 5 с (Wi‑Fi).
2. Обновить рецепт на вебе.
3. **Ожидание:** та же фраза, форматирование не ломает ProseMirror.

## SC-003 — Sticky-панель

1. Edit → tap в инструкции.
2. **Ожидание:** панель внизу экрана; tap bold — текст жирнеет; кнопка active.
3. Tap в поле количества ингредиента.
4. **Ожидание:** панель **скрыта**.

## SC-004 — Длинный текст

1. Рецепт с описанием > ~3 экранов (или искусственно вставить длинный текст на вебе, sync).
2. Edit → открыть инструкции.
3. **Ожидание:** скролл плавный, нет белого «пустого» гигантского блока; при focus-режиме — скролл внутри области текста работает.

## SC-005 — Офлайн

1. Airplane mode → Edit → изменить инструкцию → Done.
2. Выключить airplane → подождать ≤ 10 с.
3. **Ожидание:** правка на вебе.

## Phase 3+ (018)

- Ссылка с iOS кликабельна на вебе.
- Timer-нода: duration совпадает.
- Просмотр: tap timer → локальный таймер.
- Sparkles (v3): диалог offline/online как на вебе.

## Debug launch

```bash
xcrun simctl launch booted ru.recipescaler.RecipeScalerNative \
  -OpenRecipeId=<UUID> -StartInEditMode=1
```

## Build

```bash
rtk xcodebuild -scheme RecipeScalerNative \
  -destination 'platform=iOS Simulator,id=<UDID>' build
```
