# Quickstart: просмотр описания v3

**Спека**: [spec.md](./spec.md)

## Предусловия

- Аккаунт с **v3**-рецептом, у которого на вебе заполнено описание (шаги, списки).
- Backend доступен для первой sync.

## 1. Онлайн

1. Открыть v3-рецепт на вебе — убедиться, что блок описания не пустой.
2. На iOS открыть тот же рецепт.
3. **Ожидание**: секция «Instructions» с текстом; прокрутка без краша.

## 2. Офлайн

1. После п.1 включить режим полёта.
2. Force-quit, перезапуск, открыть тот же рецепт.
3. **Ожидание**: описание по-прежнему видно (из SQLite snapshot).

## 3. Обновление с веба

1. На вебе добавить абзац в описание v3.
2. Дождаться sync на iOS (или переоткрыть рецепт).
3. **Ожидание**: новый абзац появился в Instructions.

## 4. Регрессия v1/v2

1. Открыть legacy-рецепт с описанием.
2. **Ожидание**: описание как раньше; баннер legacy без изменений.

## 5. Пустое описание

1. v3-рецепт без шагов (`hasSteps == false`, пустой fragment).
2. **Ожидание**: секции Instructions нет.
