# Нативные фичи iPhone без платного аккаунта Apple

**Проект:** Recipe Scaler Native
**Статус:** платный Apple Developer Program ($99/год) пока не получен.
**Дата:** 2026-06-12

## Зачем этот документ

Это подборка фич, которые имеет смысл сделать **прямо сейчас**, пока нет платного аккаунта
разработчика. Каждый кандидат отобран по четырём критериям:

1. **Полезно** именно кулинарному приложению.
2. **Нельзя сделать в вебе** (или в вебе получается ненадёжно/уродливо).
3. **Глубокая нативная интеграция** с функциями iPhone.
4. **Не требует платного аккаунта** для разработки и проверки: всё собирается и тестируется на
   симуляторе iOS 17+, а в большинстве случаев и на личном iPhone через Personal Team
   (бесплатный Apple ID).

Что отложено под платный аккаунт (APNs push, Share/Action extensions на железе, App Groups на
устройстве, TestFlight/App Store) — описано в
[`PAID-APPLE-DEVELOPER-REQUIRED.md`](./PAID-APPLE-DEVELOPER-REQUIRED.md). Здесь мы это **не**
дублируем, а только ссылаемся.

## Матрица: что доступно без платного аккаунта

| Фреймворк / возможность | Без платного аккаунта | Примечание |
|---|---|---|
| **ActivityKit** (Live Activities, Dynamic Island) | ✅ да | Локальные апдейты без push; см. фичу 1 |
| **WidgetKit** (виджеты, Lock Screen) | ✅ да (симулятор) | Чтение данных приложения обычно через App Group → нюанс на железе |
| **App Intents** (Siri, Shortcuts, Spotlight) | ✅ да | Только код |
| **VisionKit / Vision** (OCR, сканер документов, DataScanner) | ✅ да | Нужна usage-description камеры |
| **Speech** (SFSpeechRecognizer) | ✅ да | Нужны usage-descriptions |
| **PDFKit** + AirPrint | ✅ да | Только код |
| **EventKit** (Apple Reminders / Calendar) | ✅ да | Нужна usage-description |
| **CoreHaptics** | ✅ да | Только код |
| **UserNotifications** — локальные, с экшен-кнопками | ✅ да | Без APNs |
| **NSUserActivity / Handoff / Spotlight-индексация** | ✅ да | Кастомная схема, без Associated Domains |
| **Translation** (iOS 17.4+) | ✅ да | Только код |
| Remote push (**APNs**) | ❌ платный | spec 023 |
| Share / Action **extensions** на реальном iPhone | ❌ платный | spec 025 |
| **App Groups** «надёжно на железе» | ❌ платный | см. PAID-doc |
| Universal links `https://` (**Associated Domains**) | ❌ платный (нужен portal) | Реализация: spec `059-universal-links`; схема `recipe-scaler://` работает и без платного |
| iCloud / CloudKit, Sign in with Apple, WeatherKit | ❌ платный | — |

> Важно: кастомная URL-схема `recipe-scaler://` работает **без** Associated Domains и без платного
> аккаунта. Под платный уходят только универсальные `https://`-ссылки.

## Уже сделано

### ✅ Синхронизация списка покупок с Apple Reminders (EventKit)

**Что:** список покупок зеркалируется в «Напоминания» — двунаправленная синхронизация статуса
выполнения; CRDT-список остаётся источником правды. Выполненные пункты остаются в Reminders
отмеченными, не удаляются.

**Почему без платного аккаунта:** EventKit бесплатен; нужна только usage-description.

**Бонус:** список покупок доступен в «Напоминаниях», а значит на Apple Watch, в CarPlay и у Siri.

**Связь с проектом:** spec 024 (DONE); решение зафиксировано в
[`DECISIONS.md`](./DECISIONS.md) («Apple Reminders as synced mirror»).

## Топ-кандидаты (по приоритету)

### 1. Live Activities + Dynamic Island для кулинарных таймеров ⭐

**Что:** активный таймер готовки на Lock Screen и в Dynamic Island — с живым обратным отсчётом,
названием рецепта/шага и кнопками паузы/стопа.

**Почему без платного аккаунта:** обратный отсчёт рисуется через `Text(timerInterval:)` — система
сама обновляет цифры **без push и без сервера**. Динамические данные передаются через `ContentState`
ActivityKit, **а не** через App Group, поэтому ограничение App Groups на железе здесь вообще не
мешает. Всё проверяется на симуляторе (Dynamic Island — на симуляторе iPhone 15/16 Pro).

**Почему нативно / нельзя в вебе:** Lock Screen и Dynamic Island недоступны вебу в принципе.

**Связь с проектом:** ложится поверх готовой системы таймеров (spec 014, DONE). В
[`DECISIONS.md`](./DECISIONS.md) уже зафиксировано «Production push after Live Activities» и «Timer
push requires server sync» — то есть **локальный** вариант Live Activities логично сделать первым
шагом, а серверные push-обновления (spec 023) подключить позже, уже с платным аккаунтом.

### 2. Виджеты на домашнем и Lock Screen экране (WidgetKit)

**Что:** виджеты «что готовим», закреплённые рецепты, счётчик/превью активного списка покупок,
ближайший таймер. На iOS 17 — интерактивные виджеты (через App Intents): отмечать пункты покупок
прямо из виджета.

**Почему без платного аккаунта:** разработка и проверка на симуляторе — бесплатно.

**Нюанс:** чтобы виджет читал локальные данные приложения, обычно используется App Group, который на
**реальном** устройстве с бесплатным аккаунтом ненадёжен (см. PAID-doc). Это не блокер для
разработки на симуляторе; как обходной путь виджет может тянуть данные сам (URLSession к API).

**Почему нативно / нельзя в вебе:** домашний экран и Lock Screen вебу недоступны.

**Связь с проектом:** закреплённые рецепты (pin уже есть), список покупок (spec 024, DONE), таймеры
(spec 014).

### 3. App Intents → Siri, Shortcuts, Spotlight

**Что:** действия приложения в «Командах» (Shortcuts), голосовые фразы Siri и быстрые точки входа из
Spotlight. Пользователь собирает автоматизации («если пришёл домой — открыть список покупок») или
вызывает команды hands-free во время готовки.

**Почему без платного аккаунта:** App Intents — только код, никаких порталов и entitlements.

**Почему нативно / нельзя в вебе:** системный голосовой ассистент, Spotlight и Shortcuts — чисто
нативные точки входа.

**Связь с проектом:** перекликается с ассистентом (spec 015) и таймерами (spec 014); индексацию
рецептов в Spotlight можно сделать через `NSUserActivity`/CoreSpotlight. Pause/resume таймера из
Live Activity уже используют `LiveActivityIntent` — их можно переиспользовать как основу для
общих Shortcuts.

#### Какие действия выставить (первая волна)

| Действие | Параметры | Зачем |
|---|---|---|
| **Поставить таймер** | длительность (мин/сек), подпись (шаг/рецепт) | «Siri, поставь таймер на 12 минут» |
| **Поставить на паузу / продолжить таймер** | активный или по id | hands-free у плиты; уже есть intent для Live Activity |
| **Остановить таймер** | активный или по id | сброс без открытия приложения |
| **Добавить в список покупок** | название, опционально количество/единица | «Добавь молоко в список покупок» |
| **Отметить пункт покупок выполненным** | название (fuzzy match) | быстрый чек-off из Shortcuts или Siri |
| **Открыть список покупок** | — | автоматизация «перед магазином» |
| **Открыть рецепт** | имя или id (picker из закреплённых) | «Открой рецепт борща» |
| **Добавить ингредиенты рецепта в покупки** | рецепт, все или выбранные | один тап из Shortcuts после планирования меню |
| **Открыть вкладку** | рецепты / покупки / коллекции / профиль | универсальный deep link для автоматизаций |

**App Shortcuts (видимость в «Командах»):** через `AppShortcutsProvider` закрепить 3–5 самых частых —
«Поставить таймер», «Добавить в список покупок», «Открыть список покупок», «Открыть рецепт»,
«Добавить ингредиенты в покупки». Остальные intents доступны при сборке своей команды, но не
засоряют галерею.

**Siri-фразы (примеры локализации):**

- «Поставь таймер на {duration} в Recipe Scaler»
- «Добавь {item} в список покупок»
- «Открой список покупок в Recipe Scaler»
- «Открой рецепт {recipe}»

**Spotlight (вторая волна):** индексировать названия рецептов и коллекций (`CSSearchableItem`) —
тап в Spotlight открывает рецепт через тот же intent «Открыть рецепт».

**Нюансы:** intents должны работать **офлайн** там, где данные уже в SQLite (покупки, таймеры,
кэш рецептов); для действий, требующих сеть, — понятная локализованная ошибка. Строки — только через
`LocalizedStringResource` / `.xcstrings`, не хардкод.

### 4. VisionKit OCR / сканер документов для импорта бумажных рецептов

**Что:** сфотографировать рецепт из бумажной книги или записки → распознать текст **на устройстве**
(`VNRecognizeText` / `DataScannerViewController` / Live Text) и предзаполнить форму импорта. Сюда же
— распознавание штрихкодов/QR (камера уже заявлена в `Info.plist`).

**Почему без платного аккаунта:** Vision/VisionKit — бесплатные фреймворки, нужна лишь
usage-description камеры.

**Почему нативно / нельзя в вебе:** офлайн-распознавание текста с камеры на устройстве; веб такого
качества и приватности не даёт.

**Связь с проектом:** дополняет серверный импорт по фото (specs 010/016), но работает на устройстве
и офлайн.

## Второй уровень

- **Экспорт рецепта в PDF + AirPrint (PDFKit).** Красивый PDF и печать/шеринг. Уже есть в
  user-story PDF export ([`PRD.md`](./PRD.md)).
- **Голосовой ввод на устройстве (Speech).** Hands-free во время готовки: диктовка, голосовые
  команды. Связь: ассистент (spec 015).
- **Тактильная отдача (CoreHaptics).** Завершение таймера, детенты слайдера масштабирования.
- **Не гасить экран во время готовки + StandBy** (`isIdleTimerDisabled`, режим StandBy для
  таймера). Мелочь, но в вебе ненадёжно.
- **Экшен-кнопки в локальных уведомлениях (UserNotifications).** «+1 мин» / «отложить» прямо в
  уведомлении таймера — **без APNs** и без платного аккаунта. Расширяет существующие локальные
  уведомления таймеров.

## Осознанно отложено (нужен платный аккаунт)

Remote push (APNs, spec 023), Share/Action extensions на реальном iPhone (spec 025), App Groups на
железе, iCloud-синхронизация, Sign in with Apple, TestFlight/App Store. Universal Links
(`059-universal-links`) требуют Associated Domains в портале + AASA на домене — см.
[`PAID-APPLE-DEVELOPER-REQUIRED.md`](./PAID-APPLE-DEVELOPER-REQUIRED.md) §1.2.1.

## Как проверять без платного аккаунта

- Сборка и запуск: схема `RecipeScalerNative`, симулятор iOS 17+ (`xcodebuild` / Xcode).
- **Live Activities / Dynamic Island:** симулятор iPhone 15/16 Pro; таймер должен сам тикать на
  Lock Screen и в Dynamic Island без сервера.
- **Виджеты:** добавить на домашний/Lock Screen экран симулятора; интерактив — через App Intents.
- **App Intents / Shortcuts:** приложение «Команды» → галерея Recipe Scaler (App Shortcuts) +
  ручная сборка команды из intents; Siri на симуляторе (⌘⇧H дважды → Siri). Проверить офлайн:
  таймер, добавление в покупки, открытие вкладки.
- **VisionKit / Speech / камера:** требуют разрешений — проверять на симуляторе/устройстве с
  выданными usage-descriptions.
- Образец для нового verify-скрипта — существующие `scripts/verify-*.sh`.

## Рекомендуемый порядок

1. **Live Activities для таймеров** — максимальная отдача, опирается на готовый spec 014, ноль
   зависимостей от платного аккаунта.
2. **App Intents (Siri/Shortcuts/Spotlight)** — дешёво по коду, большой нативный охват.
3. **VisionKit-импорт бумажных рецептов** — заметная фича, офлайн, дополняет серверный импорт.
4. **Виджеты** — после Live Activities (переиспользуют те же данные таймеров/покупок); помнить про
   нюанс App Group на железе.
